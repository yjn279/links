# Links Backend

The backend for the Links app will be implemented in Slice 2. It is a Cloudflare Worker written in TypeScript that handles URL metadata fetching and AI-powered summarisation/tagging via the Anthropic Claude API.

For Cloudflare Workers and Wrangler documentation see:
- https://developers.cloudflare.com/workers/
- https://developers.cloudflare.com/workers/wrangler/

Source code (`src/`, `wrangler.toml`, `package.json`) will be created in Slice 2.
